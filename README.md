# Logistics Tracking System — Online Deployment Package

Prepared for Render with React/Vite frontend, Node/Express backend, and managed PostgreSQL.

## Deploy
1. Put this folder in a GitHub repository with `render.yaml` at the repository root.
2. In Render, choose **New -> Blueprint** and connect the GitHub repository.
3. Render creates the frontend, backend and PostgreSQL resources from `render.yaml`.
4. Wait for both services to deploy.
5. Open the frontend service's `onrender.com` URL. That becomes the shared website URL for all laptops/desktops with internet access.

The exact Excel template supplied in this conversation is stored in `frontend/public/Logistics_Shipment_Upload_Template.xlsx` and the website downloads that exact file.
